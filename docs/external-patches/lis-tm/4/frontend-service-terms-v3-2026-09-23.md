# Общая оферта Y.CS: версия 3 и просмотр кабинета при блокировке

Существующий API документов возвращает `YCS_SERVICE_TERMS` с `version: "3"`, новым `contentHash` и текстом из `service-v3-ru.md`. Версии 1 и 2 сохранены как исторические. Принятие новой версии пока добровольно и не ограничивает функциональность.

Заблокированный пользователь может вызвать `POST /api/telegram/user/general/init?chatId=<chatId>`: для существующего TD метод возвращает `EXISTS` без изменения аккаунта. Затем доступен просмотр кабинета: `GET /api/web/v1/user/general/info` или `GET /api/telegram/user/general/info?chatId=<chatId>`. Ответы `info` сохраняют поля `balance` и `referralBalance` и добавляют `blockedUntil` (время UTC). При действующей блокировке фронт показывает эти суммы, срок ограничения и ссылку на поддержку, а действия по покупке, продаже и изменению настроек скрывает или отключает. Прочие пользовательские операции продолжают отвечать HTTP 403 `USER_BLOCKED`.

Оферта объясняет ограничение обслуживания, просмотр баланса, обращение за сверкой и возможным возвратом через поддержку, а также правило автоматической выдачи Bargain за личные пополнения.
