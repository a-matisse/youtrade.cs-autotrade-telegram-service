# Balance Market: активный заказ RedBalance

Новая заявка перед выпуском API-ключа проходит этап `CHECKING_RED_ORDERS`.
Если `GET /api/orders` возвращает непустой `activeOrder`, наша заявка получает
`status=FAILED`, `stage=FAILED`, `reason=REDBALANCE_ACTIVE_ORDER`.
Деньги пользователя не переводились. Сам заказ RedBalance не отменяется.

Web и Telegram API возвращают эту причину в обычном ответе заявки. Redis-событие
`BALANCE_MARKET_FAILED` передаёт её в поле `reason` по существующему контракту.
Клиент формирует сообщение: «Вывод временно недоступен: у платёжного партнёра
есть незавершённый заказ. Средства с вашего аккаунта не списывались».

При ошибке получения списка заказов заявка остаётся на начальной проверке;
она не получает `FAILED` только из-за недоступности RedBalance.
