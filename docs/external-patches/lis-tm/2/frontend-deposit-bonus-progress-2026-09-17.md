# Прогресс бонуса к пополнению в viewAccInfo

Оба существующих запроса `viewAccInfo` теперь дополнительно возвращают поле `depositBonusProgress`. Значения рассчитывает backend по той же шкале, которая определяет фактический бонус при личном пополнении через HELEKET или Telegram Stars.

```json
{
  "depositBonusProgress": {
    "turnover": 750.00,
    "currentBonusRate": 0.00,
    "locked": false,
    "nextTier": {
      "turnoverThreshold": 2000.00,
      "bonusRate": 0.05,
      "remainingTurnover": 1250.00
    }
  }
}
```

Ставки передаются долей: `0.05` означает 5%. Реальная шкала: 0% до $2,000; 5% с $2,000; 10% с $5,000; 15% с $10,000; 20% с $20,000; 30% с $40,000.

На максимальном уровне `nextTier` равен `null`:

```json
{
  "depositBonusProgress": {
    "turnover": 42500.00,
    "currentBonusRate": 0.30,
    "locked": false,
    "nextTier": null
  }
}
```

Рекомендуемая подача до следующего уровня: `Ещё $1,250 оборота — и бонус на каждое личное пополнение вырастет до 5%`. На максимальном уровне: `Максимальный бонус 30% активен`.

Если пользователю вручную закреплена ставка, backend возвращает фактическую сохранённую ставку, `locked=true` и `nextTier=null`. В этом состоянии нельзя показывать цель по обороту. Подходящая формулировка: `Для вас действует персональный бонус 15% на личные пополнения`.

```json
{
  "depositBonusProgress": {
    "turnover": 750.00,
    "currentBonusRate": 0.15,
    "locked": true,
    "nextTier": null
  }
}
```

Не рассчитывать уровень или остаток на фронте и не подменять `turnover` суммой пополнений: шкала привязана к обороту, который рассчитывает backend.
