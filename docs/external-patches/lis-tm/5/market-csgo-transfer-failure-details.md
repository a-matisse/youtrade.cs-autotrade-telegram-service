# Ошибки сбора и перевода баланса Market.CSGO

Для `POST /api/web/v1/user/accounts/v2/market-csgo/balance-transfer` и
`POST /api/web/v1/user/accounts/v2/market-csgo/money-send` в ответе есть
`failedAccountId` — ID SteamToken аккаунта, на котором остановилась операция.
Поле `cause` содержит причину ошибки: отказ Market.CSGO, HTTP-код или сбой связи.
API-ключи и платёжный пароль в текст ошибки не включаются.

При сбое чтения баланса во время сбора `failedAccountId` указывает на
проверявшийся аккаунт. При сбое отправки — на аккаунт отправителя. В ответе
сбора список `accounts` по-прежнему показывает подтверждённые, пропущенные и
неподтверждённые операции по отдельности.

При переводе на внешний API-ключ ошибка проверки получателя возвращает
`failedAccountId: null`, поскольку у получателя нет локального ID аккаунта.
`cause` прямо сообщает, что проблема возникла при проверке получателя.

## Задача для меню аккаунтов

При `result: false` показывать пользователю `cause` и `failedAccountId`, если
он задан. Если `failedAccountId` равен `null`, не подставлять вместо него ID
отправителя или получателя. При `outcomeUnknown: true` для `money-send` и
`UNKNOWN` для сбора сообщать о необходимости проверить историю Market.CSGO
перед повторной отправкой. Автоматически повторять такие запросы нельзя.

Полный контракт денежных операций описан в
[документации переводов](../market-csgo-balance-transfer.md).
