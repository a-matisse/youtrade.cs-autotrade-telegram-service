# Приветственное уведомление Y.CS

Статус: обработчик и отображение уведомления реализованы в Telegram-сервисе.
Публикация серверного события должна быть добавлена в lis-tm отдельно.

## Событие lis-tm

Отправлять через существующий поток уведомлений после успешного создания нового
пользователя при первом Telegram `/init` (`CREATED`). К этому моменту пользователь,
его параметры и выбранный язык должны быть сохранены и доступны для чтения.
Для ответа `EXISTS` событие не публикуется. Создание пользователя другими каналами
само по себе не должно вызывать Telegram-приветствие.

Формат, поддерживаемый ботом:

```json
{
  "product": "YOUTRADE_PRO",
  "type": "USER_CREATED",
  "tdId": 123,
  "chatId": 123456789
}
```

Текст, HTML и кнопки формирует бот. Язык уже доступен через `/general/info`;
для этого уведомления не нужно отдельно передавать его в событии.
При возможной повторной доставке одного события бот должен исключать повторную
отправку приветствия по `tdId`.

## Отображение в боте

Отдельное сообщение по существующему шаблону `YTNotificationMenu` с кнопками
и `isReplacing() == false`. Другие меню уведомлений сохраняют прежнее поведение.
Не заменяет `/start`, не изменяет состояние меню и не становится его
`lastMessageId`. Обычный старт и обработка `/start promo_...` продолжаются как сейчас.

Сообщение содержит фирменный заголовок, приветствие, ссылку на
`https://docs.youtradecs.xyz` и английскую подсказку:
`If needed, you can change your language below.`

Кнопка `Language` открывает существующее меню `UserMenu.LANGUAGE` только при нажатии.
Кнопка «Туториал» открывает `https://docs.youtradecs.xyz`.
Её обработка должна работать независимо от текущего меню пользователя. Нельзя
направлять обычные кнопки `/start` в обработчик приветствия или автоматически
переключать пользователя в меню уведомления при получении события.

Для кнопок этого уведомления используются callback-значения
`NOTIFICATION_WELCOME:LANGUAGE` и `NOTIFICATION_WELCOME:TUTORIAL_URL`
(у кнопки туториала фактически используется URL). Префикс определяет обработчик
уведомления через `UserMenu`; обычные callback-значения меню не меняются.
После нажатия `Language` клавиатура существующего меню языка работает как обычно.
Дедупликация использует Redis-ключ `telegram:welcome-message:{tdId}`.

Событие может прийти до или после ответа на `/start`: уведомление в обоих случаях
остаётся отдельным сообщением, порядок этих двух сообщений не гарантируется.
