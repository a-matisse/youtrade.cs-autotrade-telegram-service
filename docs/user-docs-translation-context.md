# Контекст будущего перевода документации Y.CS

Русская версия в `user-docs/` является исходной. Английский перевод делать после стабилизации структуры и добавления скриншотов.

## Термины

- Y.CS и YouTrade.CS не переводятся; в интерфейсе предпочтительно Y.CS.
- QuickConfig™ не переводится.
- Y.CS Bargain™ — название модуля автоматизации торгов; Bargain на CSFloat означает торги за дополнительную скидку.
- Y.CS Worker™ — полное название серверного модуля; не сокращать до Worker в заголовках и первом упоминании.
- «Площадка» — marketplace.
- «Ожидание» — Pending.
- «История продаж» — Sales history.
- «Оборот» — trading volume.

## Тон

Короткие прямые инструкции без предположения технических знаний. Один шаг — одно действие. Не обещать доходность и не создавать ощущение срочности. Всегда разделять баланс площадки для покупки предметов и баланс Y.CS для оплаты услуг.

## Факты, которые нельзя потерять

- Bargain — торги CSFloat за дополнительную скидку; Y.CS автоматизирует переговоры и выкуп.
- KYC требуется отдельно для каждого аккаунта CSFloat.
- Пополнение CSFloat: USDC в сети Solana или Ethereum.
- Ключ покупки доступен после операции от $0.03; ключ продажи доступен сразу.
- QuickConfig™ и базовые параметры создаются автоматически.
- В текущем маршруте площадка покупки — CSFloat, площадка продажи — Market.CS.
- API-ключ покупки берётся на вкладке Developers CSFloat; API-ключ продажи — в кабинете Market.CS.
- Для Y.CS Worker™ нужны Steam login, password и maFile.
- Покупка, продажа и Y.CS Worker™ добавляются независимо через `/accounts → Добавить` и автоматически связываются по Steam ID.
- После покупки действует 7 дней защиты предмета. После продажи площадка ещё 7 дней резервирует средства из-за Trade Reverse. Публичная видимость иногда задерживается до 10 дней.
- Поддержка: https://t.me/youtradecs_sup
- Помощь с KYC: https://t.me/buff_x, стоимость $35, использовать заранее подготовленное сообщение из русской страницы.
