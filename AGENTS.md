# Правила интерфейса сайта

Перед изменениями frontend читать раздел «Кнопки веб-интерфейса» в
[docs/ux/design-style.md](docs/ux/design-style.md) и ближайшие реализации.

- Общие кнопки сайта и обучения оформлять через `shared/site/buttons.css`.
  Использовать существующие варианты `site-control--solid`, `--accent`,
  `--quiet`, `--icon`, `--large`; не копировать стили состояний в отдельные страницы.
- Основные действия — однотонная контрастная заливка. Второстепенные и
  кнопки-иконки — без постоянной рамки; при наведении появляется однотонная
  скруглённая квадратная подложка. Фокус и нажатие имеют отдельное состояние.
- Иконки брать из общего `shared/site/icons.svg`: сетка 24, отображение 20 px,
  монохромный контур 1.75, скруглённые концы. Не использовать Unicode вместо
  иконок веб-кнопок, декоративные стрелки или отдельные несовместимые наборы.
  Логотипы провайдеров входа — исключение: сохранять оригинальные цвета бренда.
- Сохранять компактную общую шапку. Размер иконки не равен области нажатия:
  компактная кнопка 34 px, при touch минимум 36 px. Для обычных форм — от 44 px.
  Не уменьшать область нажатия ради тонкой линии или меньшей иконки.
- На всех страницах сайта использовать общую шапку и футер в принятом
  формате. «Обучение» и «Документы», ссылка «Telegram-бот» и значок группы
  Telegram размещаются в футере.
- Исходный CSS писать многострочно: правило и каждое свойство с новой строки.
  Рамки полей, таблиц и панелей не относятся к запрету лишних рамок кнопок.
- В заголовках веб-интерфейса опускать точки в конце каждой строки, в том
  числе перед явным переносом. Сохранять точки внутри названий, например Y.CS.
- Небольшое выдвижение плиток при наведении сохранять; запрет подпрыгивания
  относится к кнопкам. Для плиток учитывать `prefers-reduced-motion`.
- Ошибки операций показывать через общий `useNotifications().error(...)`.
  Хост `SiteNotifications` находится в общей оболочке, оформление — в `Toast`.
  Не создавать отдельные всплывающие уведомления в каждой странице.

Эти правила относятся к веб-интерфейсу. Оформление Telegram-кнопок и
динамические эмодзи менять по его существующим шаблонам.
