# Ожидание и история

После настройки основная работа происходит автоматически. Для контроля достаточно двух разделов.

## Ожидание

Быстрый путь: отправьте команду `/portfolio` и нажмите **Ожидание**. Здесь находятся предметы, для которых ещё не завершён текущий этап. В сообщении отображается **перспективный заработок** по ожидающим предметам. Вкладка **Общая** показывает покупки и продажи вместе.

## История продаж

Быстрый путь: отправьте команду `/portfolio` и нажмите **История → Продажи**. Здесь видны завершённые продажи, их результат и **текущий заработок** за выбранный период. Период можно выбрать готовой кнопкой или отправить своё число дней.

<figure class="doc-shot doc-shot--telegram"><img src="/images/portfolio/sales-history.png" alt="В меню выбора типа истории выделена кнопка Продажа" loading="lazy" decoding="async"><figcaption>После кнопки «История» выберите «Продажа».</figcaption></figure>

::: tip Проверяйте спокойно
Предмет в ожидании не означает ошибку. Сначала сопоставьте его возраст со стандартной задержкой Steam.
:::

Если запись долго не меняется после ожидаемого срока, пришлите её название и аккаунт в [поддержку](https://t.me/youtradecs_sup).
