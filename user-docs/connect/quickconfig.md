# QuickConfig™

QuickConfig™ уже инициализирован для нового кабинета. Он задаёт базовые параметры покупки и продажи без ручного заполнения десятков значений.

## Готово без ручной настройки

Для первого запуска достаточно использовать уже подготовленные параметры. QuickConfig™ позволяет перейти к торговле без ручного заполнения настроек; позднее конфигурацию можно изменить в любое время.

## Если нужны другие параметры

1. В боте отправьте `/start`.
2. Нажмите **Начать торговлю**.
3. В верхней строке нажмите активную кнопку **QuickConfig™**, чтобы отключить текущую конфигурацию.
4. После отключения кнопка изменит состояние. Нажмите **QuickConfig™** ещё раз, чтобы начать настройку заново.
5. Ответьте на вопросы бота: режим покупки, режим продажи и рабочий капитал.
6. Проверьте итог перед подтверждением.

::: info Углублённые настройки
Они находятся внизу меню **Начать торговлю → Углублённая**. Для обычного запуска они не нужны.
:::
