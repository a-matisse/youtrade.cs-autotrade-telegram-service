# Запустить торговлю

Покупка, продажа и Y.CS Worker™ — три независимых направления. Подключайте и включайте только те, которые нужны сейчас.

## Пополните Y.CS

Баланс Y.CS оплачивает услуги сервиса и не используется для покупки предметов.

1. Отправьте `/start`.
2. Нажмите **Пополнить**.
3. Выберите готовую сумму или отправьте своё число.
4. Завершите оплату по инструкции бота.

## Включите направления

1. Отправьте `/user`.
2. Проверьте выбранный профиль. При необходимости нажмите **Сменить**.
3. Посмотрите на кружок возле **Покупка**: красный означает, что направление остановлено, зелёный — что оно работает. Нажмите кнопку, чтобы изменить состояние.
4. Так же проверьте **Продажа**: красный кружок означает «выключено», зелёный — «работает».
5. Y.CS Worker™ начинает обслуживать трейды своего Steam-аккаунта после отдельного подключения в `/accounts`.

Если поддержка уже открыла вам доступ к Y.CS Bargain™, проверьте режим через `/deep`. **[Как подключить Y.CS Bargain™](/connect/bargain)**.

<div class="success-check">Готово, если нужные направления отмечены зелёным, а в профиле выбран правильный аккаунт.</div>

После запуска Telegram можно закрыть. Для наблюдения используйте `/portfolio`: основные разделы — **Ожидание** и **История продаж**.
