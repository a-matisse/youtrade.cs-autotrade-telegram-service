# Получить доступ к Y.CS Bargain™

**Bargain — это торги CSFloat за дополнительную скидку на предмет.** Y.CS Bargain™ автоматически отправляет предложения продавцам, продолжает торг и выкупает предмет после согласования цены.

Сейчас доступ к Y.CS Bargain™ подключается по запросу через поддержку.

[Запросить подключение Y.CS Bargain™](https://t.me/youtradecs_sup?text=%D0%97%D0%B4%D1%80%D0%B0%D0%B2%D1%81%D1%82%D0%B2%D1%83%D0%B9%D1%82%D0%B5!%20%D0%A5%D0%BE%D1%87%D1%83%20%D0%BF%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C%20Y.CS%20Bargain%E2%84%A2%20%D0%B4%D0%BB%D1%8F%20%D0%BC%D0%BE%D0%B5%D0%B3%D0%BE%20%D0%B0%D0%BA%D0%BA%D0%B0%D1%83%D0%BD%D1%82%D0%B0%20CSFloat.%20%D0%9F%D0%BE%D0%BC%D0%BE%D0%B3%D0%B8%D1%82%D0%B5%2C%20%D0%BF%D0%BE%D0%B6%D0%B0%D0%BB%D1%83%D0%B9%D1%81%D1%82%D0%B0%2C%20%D0%B0%D0%BA%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D1%82%D1%8C%20%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%20%D0%BA%20%D1%82%D0%BE%D1%80%D0%B3%D0%B0%D0%BC.)

После подтверждения поддержки:

1. Отправьте `/deep`.
2. Нажмите кнопку режима покупки, чтобы выбрать **Режим: Баргейны**.
3. Вернитесь в `/user` и включите **Покупка**.

::: info Можно начать без Y.CS Bargain™
Обычная автопокупка работает без доступа к торгам. Однако без дополнительной скидки эффективность стратегии будет ниже максимальной.
:::
