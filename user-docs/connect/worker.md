# Y.CS Worker™

Y.CS Worker™ — серверное программное обеспечение, которое поддерживает активную торговую сессию Steam, принимает купленные предметы и передаёт проданные. Он нужен для автоматической обработки трейдов, но покупка и автопродажа могут работать независимо от него.

## Подготовьте

- логин Steam;
- пароль Steam;
- файл `maFile` от Steam Guard для этого аккаунта.

## Добавление

1. Отправьте боту команду `/accounts`.
2. Нажмите **Добавить**.
3. Выберите **Воркер**.
4. Ответьте на первое сообщение **логином Steam**. Это логин для входа, а не отображаемое имя профиля.
5. Ответьте на следующее сообщение паролем.
6. В ответ на последний запрос отправьте `maFile` как файл.
7. Дождитесь подтверждения подключения.

Бот удаляет каждое сообщение с чувствительными данными сразу после обработки. Y.CS Worker™ автоматически привязывается по Steam ID к подключённым аккаунтам покупки и продажи.

Инструмент следует данным площадки продажи и передаёт предмет только по подтверждённой операции.

::: warning Нет maFile
Полностью автоматическая передача предметов без `maFile` невозможна. Инструкция по его подготовке доступна по кнопке прямо в диалоге добавления Y.CS Worker™.
:::
