# Куда вы переводите деньги

У вас будут два независимых баланса.

| Баланс | Для чего нужен |
|---|---|
| **CSFloat** | Покупка предметов на торговой площадке |
| **Y.CS** | Оплата автопокупки, Y.CS Bargain™, автопродажи и Y.CS Worker™ |

Сейчас Y.CS не хранит бюджет, предназначенный для покупки скинов, и пока не тратит свой баланс на сделки площадки. Баланс сервиса используется только для оплаты его услуг.

## Сколько капитала размещать на аккаунте

<div class="capital-scale">
  <div class="is-fragmented"><b>$1–2 тыс.</b><strong>Слишком дробно</strong><span>Потребуется слишком много аккаунтов</span></div>
  <div class="is-balanced"><b>$4–5 тыс.</b><strong>Безопасный ориентир</strong><span>Баланс диверсификации и управления</span></div>
  <div class="is-concentrated"><b>$10 тыс.+</b><strong>Опасная концентрация</strong><span>Слишком большая доля капитала на одном аккаунте</span></div>
</div>

Безопасный ориентир — **один аккаунт на каждые $4,000–5,000 общего капитала**. Для $20,000 это примерно 4–5 аккаунтов. При $1,000–2,000 на аккаунт инфраструктура становится избыточной, а при $10,000 и более риск чрезмерно концентрируется в одном месте.

Это обычный экономический принцип диверсификации: капитал распределяется между независимыми аккаунтами, поэтому проблема одного аккаунта не останавливает весь оборот.

При этом свободный баланс внутри одного аккаунта желательно пополнять частями примерно до **$1,500 за раз**. Остальной капитал постепенно переходит в предметы и возвращается в баланс после завершения торгового цикла.
