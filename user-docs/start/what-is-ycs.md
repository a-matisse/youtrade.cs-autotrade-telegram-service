# Что делает Y.CS

Y.CS автоматизирует покупку и продажу предметов CS2. Вы один раз подключаете торговую площадку и Steam-аккаунт, затем сервис выполняет заданные действия и собирает историю.

## Площадки в этой инструкции

Дальше **площадкой покупки** мы называем CSFloat, а **площадкой продажи** — Market.CS. Сервис связывает их через Steam ID и ведёт предмет от покупки до продажи.

::: tip Базовая настройка уже выполнена
После создания кабинета сервис автоматически подготавливает параметры и QuickConfig™. Можно сразу использовать готовую конфигурацию. Менять её нужно только тогда, когда вы уже понимаете, какие параметры хотите настроить иначе.
:::

## Что потребуется

- Telegram и бот [@youtradecs_bot](https://t.me/youtradecs_bot);
- аккаунт Steam без ограничений на обмен;
- аккаунт CSFloat с пройденной верификацией;
- USDC для пополнения CSFloat;
- для Y.CS Worker™: логин Steam, пароль и файл `maFile`.
