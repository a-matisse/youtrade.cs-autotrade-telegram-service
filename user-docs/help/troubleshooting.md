# Если что-то не работает

## Аккаунт не появился

Отправьте `/accounts` и переключите режим списка: покупка, продажа или Worker. Если записи нет, снова нажмите **Добавить**, выберите нужный тип и повторите ответы на сообщения бота.

## Нет ключа покупки CSFloat

Совершите на CSFloat покупку или продажу от $0.03, затем снова откройте вкладку **Developers**.

## Покупка не начинается

Проверьте по порядку:

1. на CSFloat есть свободный баланс;
2. на Y.CS есть баланс для комиссии;
3. выбран правильный аккаунт;
4. **Покупка** включена;
5. QuickConfig™ активен;
6. если вы используете Y.CS Bargain™ — доступ уже открыт и в `/deep` выбран режим баргейнов.

## Нужна помощь человека

Напишите [@youtradecs_sup](https://t.me/youtradecs_sup). Чтобы вопрос решили быстрее, укажите:

- на каком шаге остановились;
- название аккаунта в Y.CS;
- текст ошибки;
- скриншот без паролей, API-ключей и платёжных данных.
