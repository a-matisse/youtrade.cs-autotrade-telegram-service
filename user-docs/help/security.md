# Безопасность

- Открывайте Y.CS только через [@youtradecs_bot](https://t.me/youtradecs_bot).
- Основная поддержка — [@youtradecs_sup](https://t.me/youtradecs_sup).
- Не отправляйте API-ключи, пароль Steam или `maFile` в обычную переписку.
- Никому не сообщайте seed-фразу кошелька и коды подтверждения вывода.
- Перед переводом USDC сверяйте монету, сеть и адрес.
- Проверяйте получателя и состав каждого Steam-трейда.

Y.CS Worker™ использует данные площадки и работает с передачей предмета по подтверждённому сценарию продажи. Если трейд выглядит незнакомо, не подтверждайте его вручную и обратитесь в поддержку.
