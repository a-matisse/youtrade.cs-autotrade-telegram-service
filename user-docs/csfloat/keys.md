# Ключ покупки CSFloat

API-ключ позволяет Y.CS выполнять покупки на CSFloat. Он становится доступен после первой покупки или продажи на сумму от **$0.03**.

## Разблокируйте ключ покупки

Если ключ ещё недоступен, вручную совершите на CSFloat одну покупку или продажу стоимостью не меньше $0.03. Этот процесс показан в **[видео по CSFloat](/csfloat/account#видео-весь-путь-на-csfloat)**. После завершения операции снова откройте вкладку **Developers**.

## Скопируйте ключ

1. Откройте профиль CSFloat и перейдите на вкладку **Developers**.
2. Найдите API-ключ CSFloat.
3. Копируйте значение целиком, без пробелов в начале и конце.
4. В Y.CS отвечайте ключом на соответствующее сообщение бота. Бот удалит ваш ответ из чата сразу после получения.

::: tip Интерфейс площадки может измениться
Если раздел ключей выглядит иначе или ключ покупки не появился после сделки, отправьте скриншот без видимых ключей в [поддержку](https://t.me/youtradecs_sup).
:::
