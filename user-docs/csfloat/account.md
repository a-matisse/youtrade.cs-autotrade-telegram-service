# Аккаунт и верификация CSFloat

CSFloat — площадка, на которой будет находиться бюджет для покупок. Для каждого подключаемого аккаунта нужна отдельная верификация.

## 1. Создайте кабинет

1. Откройте [csfloat.com](https://csfloat.com/).
2. Войдите через тот Steam-аккаунт, который планируете использовать для торговли.

<div class="success-check">Готово, если после входа открылся ваш личный кабинет CSFloat.</div>

## 2. Пройдите верификацию

Для пополнения криптовалютой Stripe запросит KYC: подтверждение личности. Проходите его только на официальной странице, открытой из кабинета CSFloat.
